# Local development

## Requirements

- Node.js 20.9 or newer (developed and tested on Node 22)
- npm
- Optional: a Supabase project (for real data), a Razorpay **test** account (for payments)

## 1. Install and run in preview mode

```bash
npm install
npm run dev
```

Open http://localhost:3000. With no `.env.local`, the site uses the sample catalogue from `src/lib/demo-data.ts`. The cart works; website checkout and the admin are disabled with clear messages.

## 2. Connect Supabase

1. Follow [SUPABASE_SETUP.md](SUPABASE_SETUP.md) to create the project, run the migrations and create the owner account.
2. Copy the env template and fill in the Supabase values:
   ```bash
   cp .env.example .env.local
   ```
3. Restart `npm run dev`. Sign in at http://localhost:3000/admin/login.

## 3. Add Razorpay test keys

1. Follow [PAYMENTS.md](PAYMENTS.md) → "Test mode".
2. Put `rzp_test_…` keys in `.env.local` with `PAYMENTS_MODE=test`.
3. In **/admin/settings → Payments**, tick "Accept Google Pay / UPI online".
4. Place an order and pay using Razorpay's test UPI flow.

### Testing webhooks locally

Razorpay can't reach `localhost`. Use a tunnel (for example `cloudflared tunnel --url http://localhost:3000` or ngrok) and register `https://<tunnel>/api/payments/razorpay/webhook` as a **test-mode** webhook. Without webhooks, payments still verify through the Checkout callback and the "Check payment status" button.

## 4. Add the logo

Save the official logo as `public/brand/kriva-logo.png` (transparent PNG, ideally at least 400 px tall). It is displayed at a fixed height with its natural proportions, never stretched. Until then a plain-text placeholder is shown.

## 5. Checks before committing

```bash
npm run check   # lint + typecheck + tests + production build
```

## Notes

- Fonts (Bodoni Moda, Instrument Sans — SIL Open Font License) are self-hosted from `src/fonts`, so builds never need Google Fonts access.
- Sample illustrations are generated by `npm run generate:samples` (`scripts/generate-sample-art.mjs`).
